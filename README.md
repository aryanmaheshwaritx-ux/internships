# Internship Portfolio — Aryan Maheshwari

Live site: https://aryanmaheshwaritx-ux.github.io/internships/

This repository contains the internship portfolio, its project media, and the current resume.

## Files

- `index.html`: portfolio page.
- `Aryan_Maheshwari_Resume_Internship.pdf`: current downloadable resume.
- `Aryan_Maheshwari_Resume_Internship.txt`: editable text of the same resume.
- `aryan_headshot_circle.png`: profile photo.
- `images/`: project gallery photos.

The PDF and text resume contain the same information. The previous Word file is available in Git history.

## Updating content

Edit the existing bio, skills, experience, and club entries in `index.html` rather than adding duplicate sections. Keep the PDF and text resume in sync. The resume download button uses the existing PDF filename.

Project descriptions and media are maintained separately from resume updates. Some project media use absolute links to the separate `portfolio` site; preserve those URLs when updating the internship portfolio.

## Publishing

GitHub Pages serves this repository at the live URL above. After changes deploy, check the updated text, resume download, and project galleries.
